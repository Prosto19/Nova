# NOVA для жюри

**[Открыть NOVA онлайн](https://prosto19.github.io/Nova/)**

Для быстрой проверки откройте [кабинет студента](https://prosto19.github.io/Nova/?onboarding=student1), подайте заявление и запомните номер. В том же браузере откройте [кабинет деканата](https://prosto19.github.io/Nova/?onboarding=dean), затем «Документооборот». Найдите свой номер и измените статус. Вернитесь по ссылке студента, чтобы увидеть результат.

База сохраняется на устройстве проверяющего. Используйте один профиль браузера для всех ролей. Встроенные команды NOVA работают прямо на странице. Свободные ответы Ollama доступны в локальной версии.

## Запуск версии для Windows

1. Скачайте [NOVA-Windows-x64.zip](https://github.com/Prosto19/Nova/releases/download/v0.2.0/NOVA-Windows-x64.zip) и полностью распакуйте архив в свою папку.
2. На компьютере с Windows 10/11 x64 дважды нажмите **Start-NOVA.cmd**. Браузер откроется автоматически. Если он не открылся, скопируйте адрес из окна NOVA.
3. На стартовом экране выберите тестовый вход. Для начала используйте кабинет студента. Оставьте окно запуска открытым до конца просмотра.

В комплекте есть сервер, среда запуска, озвучка и демонстрационные данные. При первом запуске создаётся персональная копия учебной базы. Регистрацию можно пропустить. Порт выбирается автоматически.

## Что попробовать за три минуты

| Кто | Действие | Что проверить |
|---|---|---|
| Студент | В разделе «Справки и заявления» отправьте заявление с текстом «Прошу справку для общежития». | Запомните номер заявления. |
| Сотрудник деканата | Откройте «Документооборот», найдите тот же номер и нажмите «Рассмотреть». | Переведите заявление в статус «На рассмотрении». |
| Тот же студент | Снова откройте «Справки и заявления». | У заявления появился новый статус. |
| Студент и преподаватель | В разделе «Чат» откройте диалог и обменяйтесь сообщениями. | Ответ появится в открытом диалоге. |

Для переключения ролей удобно открыть стартовый адрес из окна NOVA в другом профиле браузера или в приватном окне. Можно также выйти из кабинета и выбрать следующую роль в том же окне.

Попробуйте написать NOVA «Покажи расписание» или «Напиши преподавателю личное сообщение». Встроенные действия, календарь, документы и аудиоэкскурсии доступны сразу. Для **свободных вопросов** нужна отдельно установленная локальная Ollama с моделью qwen2.5:1.5b. Инструкция есть в README проекта. Используйте вымышленные данные.
