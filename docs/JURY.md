# NOVA · Гид для жюри

**[Открыть NOVA в браузере](https://prosto19.github.io/Nova/)**

NOVA — демонстрационный цифровой деканат. Студент подаёт заявления, преподаватель общается с группой, а сотрудник деканата обрабатывает запросы. Для просмотра достаточно браузера на компьютере или телефоне. Все учебные данные вымышлены.

**Быстрый вход:** [Студент](https://prosto19.github.io/Nova/?onboarding=student1) · [Преподаватель](https://prosto19.github.io/Nova/?onboarding=teacher) · [Деканат](https://prosto19.github.io/Nova/?onboarding=dean)

## Одна справка за три минуты

1. **Студент.** Откройте «Справки и заявления», выберите «Справка об обучении», напишите «Для общежития» и нажмите «Отправить в деканат». Запомните номер.
2. **Деканат.** Перейдите по ссылке «Деканат» выше. В «Документообороте» найдите свой номер, нажмите «Рассмотреть» и подтвердите переход в статус «На рассмотрении».
3. **Снова студент.** Вернитесь по ссылке «Студент» и откройте «Справки и заявления». У справки будет тот же номер и новый статус.

**Используйте один профиль браузера для всех трёх шагов.** Онлайн-демо сохраняет изменения на вашем устройстве. У других участников своя копия базы.

## Что ещё посмотреть

| Возможность | Как проверить |
|---|---|
| Ассистент NOVA | Напишите «Покажи расписание». Занятия появятся прямо в диалоге. |
| Личная переписка | Напишите NOVA «Напиши преподавателю личное сообщение», выберите адресата и подтвердите текст. Можно также отправить сообщение вручную в разделе «Чат». |
| Календарь | Откройте «Расписание», переключитесь с недели на месяц и выберите день. |
| Объявления | Откройте «Объявления». У каждой публикации видны автор, дата и аудитория. |
| Голосовая экскурсия | При первом входе NOVA покажет функции выбранной роли. Экскурсию можно пропустить или повторить через «Знакомство с NOVA». |

## О проекте

В браузере доступны встроенные команды NOVA. Свободные ответы через Ollama поддерживает локальная версия. [Исходный код и технологии](https://github.com/Prosto19/Nova)
