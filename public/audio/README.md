# Озвучка NOVA

Используется Silero TTS **v5_cis_base_nostress**, женский русскоязычный голос **ru_ekaterina**. Это самостоятельный голос модели; имитация или клонирование голосов Алисы / ChatGPT не выполнялись.

- Официальная документация: https://github.com/snakers4/silero-models#v5-cis-base-models
- Лицензия семейства CIS Base: MIT, https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS
- Копия уведомления: `LICENSE.txt` рядом с аудио.
- Источник весов (основной сервер был недоступен): https://huggingface.co/adeshkin/silero-models-v5-cis-base-nostress/resolve/main/v5_cis_base_nostress.pt
- SHA-256 использованного файла: 0405777e332906f0644e08a680f7cfdc2137ea864090079c1fdd30a43c1b8761
- Генерация: локально, PyTorch CPU, WAV PCM 16 bit, 24 kHz, mono; восемь отдельных реплик.
- Тексты принадлежат проекту NOVA. Подписка, внешние TTS-запросы при воспроизведении и секретные ключи не нужны.

Важно: MIT относится именно к CIS Base. Другие семейства Silero могут иметь ограничения на коммерческое использование. При замене модели проверяйте её лицензию отдельно.

Воспроизведение запускается автоматически, если браузер разрешает. Иначе показана кнопка «Включить звук». Следующий этап включается по событию ended с паузой 850 мс. Без звука пользователь листает этапы кнопкой «Далее». Завершение и пропуск сохраняются отдельно по логину в localStorage данного браузера; синхронизации между устройствами без backend нет. Для повторного запуска доступна кнопка «Знакомство с NOVA».
